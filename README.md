# KII

This is the official portfolio and music website for KII, live at [kii-sa.vercel.app](https://kii-sa.vercel.app/).

The site is designed as a modern artist landing page that introduces KII, presents his music and releases, and gives fans a direct route to stream, connect, and explore his work.

## What this website is

This project is a static artist website built to showcase:

- KII’s artist identity and brand
- Biography and background story
- Featured and catalog music releases
- Embedded video content
- Social links and contact channels
- A strong visual presence for music promotion

It is a lightweight front-end site intended to act like a digital press kit and fan portal.

## Tech stack

This project uses a simple static web stack:

- HTML for page structure
- CSS for layout, styling, responsive design, and visual effects
- JavaScript for interactive release tabs, modal popups, and video switching
- Static image and media assets stored locally in the project

There is no backend or framework required for the site to run.

## Local setup

To run this project locally:

```bash
git clone https://github.com/kvnxmars/kii-site
cd kii-site
```

Then open the project folder and run the homepage file directly:

```bash
index.html
```

You can also open it in a browser from the file explorer, or serve it with a local static server if preferred.
